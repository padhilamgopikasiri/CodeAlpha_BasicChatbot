# CodeAlpha_BasicChatbot
My Python Internship Task 3 - Basic Chatbot
CodeAlpha Basic Chatbot

Project Overview

This is my Task 3 Python project completed as part of my CodeAlpha Python Internship.

The Basic Chatbot is a simple rule-based chatbot developed using Python. It responds to predefined user messages.

Features

- Greets users.
- Responds to basic questions.
- Recognizes predefined messages.
- Handles unknown messages.
- Exits when the user types "bye".

Technologies Used

- Python
- if-elif-else statements
- while loop
- Functions
- User input and output

How to Run

1. Download the "BasicChatbot.py" file.
2. Open it using Python IDLE.
3. Run the program.
4. Type messages to interact with the chatbot.
